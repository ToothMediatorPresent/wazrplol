## ⚙️ How it works

🔍 Reads crash dumps - the tool quietly scans the dump files left behind after a crash, picking up the clues the game leaves behind.

🧠 Finds the root cause - it analyzes those dumps to pinpoint what actually went wrong.

🛠️ Fixes the related errors - once the cause is clear, it repairs the linked errors and corrupted bits automatically.

🔁 Prevents repeats - the fix sticks, so the same crash doesn't come back to haunt you.

😌 You just play - no logs to dig through, no manual patching. Launch patchwdfix.exe and enjoy.
